## Tested dependency interfaces

Install optional runtime dependencies with `uv sync --project services/api --extra team --python 3.12`. BAND is pinned to SDK 9.1.0. AdaL SDK 0.3.0 is pinned to official source commit `8fc658151e7ffebbe3fdd0b915dc01dbe2ee44be`. These pins have isolated interface tests, not a live two-agent handshake.

- [BAND quickstart](https://docs.band.ai/quickstart): four separately authenticated identities (controller, Scout, Skeptic, Builder), one pre-created room with all participants. Set `BAND_ROOM_ID`, JSON `BAND_IDENTITIES` and server-only JSON `BAND_API_KEYS`, plus `BAND_ENABLED=true`. Each key must correspond to its identity. The adapter explicitly subscribes only to the configured room; SDK auto-subscription and contact automation are disabled. Every task/reply mentions its recipient and checks the returned recipient receipt. Raw REST writes set retries to zero. A locally registered pending task and authenticated sender must match before a provider can run. Existing unrelated room traffic cannot trigger a paid call. Room/session/message IDs remain private database routing metadata.
- [Agent37 exec](https://www.agent37.com/docs/agents-api/exec.md): set `AGENT37_API_KEY`, `AGENT37_INSTANCE_ID`, `AGENT37_WORKER_REVISION` (40-character reviewed commit containing the worker), and `AGENT37_ENABLED=true`. Provision the pinned checkout and Python environment at `/app/sueperman`; the fixed command verifies `git rev-parse HEAD` before running `app.collaboration.scout_worker`. The worker performs the supported CPSC lookup without purchase data or control-plane credentials. Actual sandbox network restrictions, process cleanup and credential scope must be verified before `AGENT37_ISOLATION_VERIFIED=true`. No allocation or provisioning was performed by this implementation.
- [AdaL SDK permissions](https://docs.sylph.ai/integration/sdk/permissions/): install/authenticate the CLI in a restricted runtime. Supply `ADAL_RUNTIME_PATH` pointing to a reviewed **OS-isolating launcher**, its SHA-256 as `ADAL_RUNTIME_SHA256`, and `ADAL_ENABLED=true`. The launcher must remove unrelated environment secrets, deny filesystem mutation outside its temporary workspace, and restrict network access to required authenticated AdaL runtime services. Only set `ADAL_ISOLATION_VERIFIED=true` after observed denial tests. A raw unrestricted CLI is insufficient. SDK options explicitly disable Bash/Edit/Read/Search/Web/Image/Video/Consult and deny every tool callback, including custom tools. Evidence and skill text are supplied in the prompt. The SDK's empty enabled-tool list would be omitted, so it is deliberately not used. Authentication tokens are not supplied in process arguments. The repository now supplies `scripts/adal_isolated_runtime.py`; its Docker boundary and actual SDK wire protocol pass synthetic denial tests. The native authenticated CLI remains unavailable.
- [Finch delivery](https://www.finchtech.ai/en/story/use-skills): obtain the actual suitable package, record its exact marketplace identity/version/license/delivery URL, review every file, and hash downloaded bytes. Set `FINCH_PACKAGE_PATH`, `FINCH_MANIFEST_PATH`, `FINCH_ENABLED=true`. The manifest schema is `SkillManifest` in `adapters.py`: identity, version, license, package_sha256, delivery_url and review_record. For ZIP delivery also set primary_document (default SKILL.md) and primary_sha256. ZIPs are read in memory with size/path/duplicate/symlink checks; nothing is extracted or executed. Only the hash-checked primary Markdown is supplied to AdaL. The downloaded package hash binds approval and is rechecked before export. A manifest alone does not prove delivery or sponsor acceptance.
- [Lyzr v3 inference API](https://docs.lyzr.ai/enterprise/api/agents/chat): create a Studio Builder with structured output matching `CaseResult`, no arbitrary-fetch or submission tools. Copy the workspace's generated URL and profile, then set `LYZR_CHAT_URL`, `LYZR_API_PROFILE`, `LYZR_AGENT_ID`, `LYZR_USER_ID`, `LYZR_API_KEY`, `LYZR_ENABLED=true`. Supported explicit profiles are `v3_inference` at `https://agent-prod.studio.lyzr.ai/v3/inference/chat/` and `v3_agent` at that host's `/v3/agent/{id}/chat`. No v2 URL is guessed. The adapter sends one x-api-key-authenticated POST, uses a stable pseudonymous session per case, refuses redirects, and validates strict response identity/citations before deterministic verification.

All credentials stay server-side. `.env.example` lists blank fields, not working credentials. Test fixtures force all live flags off and clear sponsor keys. Local source/unit/browser acceptance does not contact sponsors.

## Bounds and failure semantics

One active collaboration globally, a default 30 starts/day including answer revisions, one shared maximum 90-second deadline, three addressed role tasks, two model requests (AdaL and Lyzr), one source command, no automatic paid retry. Role tasks run sequentially. Source work shares the remaining deadline with the existing maximum 75-second source limit. SDK connection setup consumes the same deadline. Shutdown is bounded separately to five seconds; exceeding the run ceiling leaves the result partial. Provider-internal model/tool costs are not observable until live traces are captured and are not guaranteed by these application counters.

Read-only configuration check: `services/api/.venv/bin/python scripts/diwali_preflight.py` (exit 2 while setup or the kill switch is incomplete; performs no live calls).

The source task first persists a non-exportable discovery revision. Its verified source creates the final material revision; a recorded origin task permits exactly that Scout-to-Skeptic handoff. Final case revisions bind product facts, source hashes, rule version and the downloaded skill hash. Every task intent and result is committed before the next state change. Unconfirmed startup work is marked partial; no transparent worker recovery is promised.

## Restricted AdaL launcher

Set `ADAL_RUNTIME_PATH` to the absolute `scripts/adal_isolated_runtime.py` path and `ADAL_RUNTIME_SHA256` to its SHA-256. Put only the reviewed native CLI bundle in `ADAL_BUNDLE_DIR`, and set `ADAL_BUNDLE_SHA256` using `app.collaboration.adal_sandbox.bundle_digest`. Put only scoped cached AdaL authentication in `ADAL_AUTH_DIRECTORY`; never point it at your whole home directory. Set `ADAL_SANDBOX_IMAGE` to an already-present, reviewed `sha256:` Docker image ID containing Python, and `ADAL_ALLOWED_HOSTS` to verified exact runtime HTTPS hosts, comma-separated. The launcher requires project Python dependencies on its executable PATH.

The container runs nonroot, without a network interface, with a read-only root and auth/bundle mounts, dropped capabilities, no-new-privileges, resource limits and only its temporary workspace writable. A Unix-socket bridge permits CONNECT only to approved public hostnames on port 443, preserving end-to-end TLS. No wildcard/private-IP destination is accepted. SDK tools remain disabled and all tool requests denied. Tests use a synthetic executable through the real SDK; they do not validate real authentication layout, native behavior or actual required hosts. Re-run denial and authenticated session checks on the supplied bundle before marking isolation verified.

The official native installer URL returned HTTP 403 from this environment; no downloaded installer was executed and no security setting was relaxed. A reviewed native bundle and authenticated account are still needed. Do not enable broad network access to work around missing endpoint information.

Store secrets in an ignored repository-root `.env` or backend process secret environment; keep mode flags off until verified. Never send secrets in chat or add them to evidence. See `.env.example` for exact names. Finch package review and local authored draft are recorded in [Finch review](finch-review.md).
